# Tamagotchi Simulator

A terminal-based Tamagotchi game written in Python.

Repository: [Tamagotchi Simulator](https://github.com/HieuHuyNguyenzz/tamagotchi_simulator)

## Run the program

```bash
python main.py
```

The game creates `save.json` automatically on first launch.

## Features

- Manage three virtual pets.
- Feed, play, sleep, heal, and rename pets.
- Track hunger, health, boredom, and exhaustion.
- Random events: food, sickness, and health bonuses or penalties.
- Game statistics.
- Save progress to JSON and automatically load it at startup.
- Start over with New Game.
- Pet values change over time.
